# ── Object storage (Cloudflare R2) ──────────────────────────────────────
# Tùy chọn — chỉ cần khi chạy `npm run images:mirror` (scripts/mirror-images-to-r2.ts)
# để tải ảnh đang hotlink từ Enka/Fandom/miHoYo về tự host, tránh phụ thuộc
# nguồn ngoài về lâu dài. Nếu để trống, app vẫn chạy bình thường — ảnh tiếp
# tục hotlink như hiện tại.
#
# Cách lấy giá trị:
#   1. Tạo bucket tại https://dash.cloudflare.com → R2
#   2. R2 → Manage API Tokens → tạo token có quyền Object Read & Write
#      -> ra R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY
#   3. Bucket vừa tạo → Settings → Public access → "Connect Domain"
#      (bucket R2 KHÔNG public theo mặc định, bắt buộc bước này để ảnh
#      truy cập được từ browser) -> ra R2_PUBLIC_URL

# R2_PUBLIC_URL PHẢI là Custom Domain public (bước 3 ở trên), TUYỆT ĐỐI
# KHÔNG được là chính R2_ACCOUNT_ID hay endpoint dạng
# "https://<accountId>.r2.cloudflarestorage.com" — đó là endpoint API RIÊNG
